# 進み具合の報告と、判断の問いかけは session-status の形で書く

ユーザーは、セッションの経緯を追わずに報告を読むことがある。何を目指し、どこまで進み、
何を決めればよいかが、報告だけで分かるようにする。

**次のどれかに当たったら、`session-status` スキルを使う。問われたとき以外は、ユーザーに言われなくても使う。**

- 状況を問われたとき。
- 複数のタスクにまたがる作業が一区切りつき、結果と残りを報告するとき。
- ユーザーに判断を求めて、手を止めるとき。
- 長い作業の途中で、ここまでの進み具合を伝えるとき。

1つの作業の完了を知らせるだけの報告や、手を止めずに続けながら伝える一言は、普段どおりに書く。
