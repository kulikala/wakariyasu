# README の書き方

ここでいう README はリポジトリの最上位に置き、ツールを外部に公開するための文書だ。読み手はツールを試すか
決める人、インストールする人、使い始める人で、このツールが何であり、どうセットアップすれば使えるかを
README だけで知ろうとする。読み手は章の名前を手がかりに必要な所へ飛ぶので、日本語の README は、人が手で
保守している日本語の README で見慣れた章の名前・組み立て・言葉で書く。

リポジトリに README の書き方を決めた文書があれば、それを先に読んで従う。その文書が決めていない点は、
この書き方に従う。この書き方に無い章の名前や言い回しは、ファイルやウェブを読めるなら、同じ分野で人が
日本語の README を保守しているツールをいくつか開き、そこで使われている形に合わせる。

## 章

章の並びと数はツールに合わせて選べる。読み手は何のツールかを知り、自分の環境で動くかを確かめ、
インストールし、使い始める、の順に読み進めることが多いので、その順に沿う並びは探しやすい。
ツールに当てはまらない章は立てない。長くなる細部は別の文書に分け、README の該当する章からリンクする。

1つの章にはその章の目的に当たる中身だけを書く。読み手は章の名前で飛んで、その章だけを読むので、ほかの章の
中身が文の中に紛れると、探した章では見つからず、読んだ章の判断も揺らぐ。向かない用途を述べる文に「…のオプションを
使うと〜できます」と使い方を続けるような書き方は、使い方を使い方の章に書き、元の章からはその章へリンクする。
1つの文を書いたら、その文がどの章の目的に当たるかを確かめる。

章ごとの目的は次のとおり。

- 冒頭の説明：ツールが何をするかと、出力の例を示し、読み手が自分の用途に合うかをすぐに判断できるようにする。
- 機能：ツールに、利用者が別々に使える機能のまとまり（別のコマンドやモード）があれば、その名前と働きを、
  名前を初めて使う章より前に一覧で示す。名前の意味を知らないと、読み手は以降の章についていけない。
- 特長：ツールを選ぶ理由になる性質を書く。出力の形式やオプションのような仕様は、使うときに探すので、
  使い方の章に置く。
- 向いている用途：ツールが受け持つ範囲と、向く用途・向かない用途を書く。ツールの前後で利用者がする作業は、
  受け持つ範囲の説明として書き、向かない用途に並べない。並べると、ツールを使う流れの一部が、合わない使い方の
  ように読める。
- 免責事項：ツールの出力の扱いと保証の有無を書く。出力に誤りが残るツールなら、どんな誤りが残りやすく、利用者が何を
  確かめるかを書く。損害の免責のような法的な文はライセンスに任せる。
- 対応環境：読み手が自分の環境で何が動くかを確かめられるように、表で示す。使いたい人が多いのに対応していない
  環境も表の行にして非対応と書く。読み手は自分の環境を表の中で探すので、行が無いと対応しているかが分からない。
- 必要なディスク容量の章と、別途必要なソフトウェアの章：インストールの前に読み手が確かめることを、それぞれの章に
  まとめて書く。ほかの章ではくり返さず、その章へリンクする。
- インストール：読み手が自分の環境の節だけを読めばよいように環境ごとに分け、どこで何を実行するかを書く。
- 使い方：最初の1回を動かすまでの手順と、よく使う操作を書く。
- 開発者ガイドとライセンス：開発に参加する人に向けた手順と、利用の条件を書く。

保守していない古いバージョンを使う案内は書かない。読み手が古いバージョンの手順を最新のバージョンの手順と取り違え、直らない不具合のあるバージョンを
使い始めるからだ。古いバージョンから移る利用者がいるなら、移る手順だけを書く。

## 用語

読み手は翻訳調の言い回しや見かけない語に出会うと、文書を信頼しにくくなり、意味も取り違える。言葉は、人が手で
保守している日本語の技術文書で見かける語を選ぶ。迷ったら、その語をそうした文書で見かけるかで決める。

- 一般の語：作業や物を指す語は、日本語の技術文書で定着した語を使う。日本語では使わない言い回しと、代わりに
  使う語は、wakariyasu の一覧（`references/terms.tsv`）にある。一覧に無い語も同じ考え方で選ぶ。
- ツールの語：ツールのコマンドや画面、出力に出る語は、利用者が画面と見比べるので、そのまま使い、初めて出る所で
  意味を添える。
- 書き手の造語：書き手が作業の中で付けた呼び名は、ツールの外では通じないので使わず、中身を表す一般の語に
  替える。替えるときは、替えた語を英語に直し、指すものの中身と合うかを確かめる。
- 章の名前：日本語の README で見かける名前を使う。英語の見出しを直訳した名前は、日本語の README では見かけない。

## 仕上げ

書き終えたら、wakariyasu の規則 `writing-documents` の「書き終えたら」の順で仕上げる。日本語の推敲のスキル
yomiyasu を使えるなら、文書の種類として `article`（技術記事・README）を渡す。
