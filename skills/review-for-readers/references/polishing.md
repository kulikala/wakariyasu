# 書いた日本語は、渡す前に整える

整えるのは読みやすさのため。主張・条件・数値・言い切りの強さは変えない。

## 表記は文章ごとに選ぶ

かなと漢字の使い分け、数字の書き方、体言止め、常体と敬体は、文章の種類で変わる。
一律には決めず、次の順で選ぶ。

1. ユーザーの指示（CLAUDE.md や AGENTS.md に書かれた指示を含む）。
2. 同じ文書や同じリポジトリで、すでに使われている書き方。
3. 文章の種類ごとの既定。ユーザーへの返答は、敬体の文で書き、体言止めにしない。
   コミットや PR の変更点の行は、体言止めを使ってよい。README・仕様書・規則の本文は、
   見出しのほかは文で書く。種類ごとの既定の表は、wakariyasu のスキルの `references/styles.md` にある。

## yomiyasu が使えるなら、yomiyasu で整える

使えるスキルの中に yomiyasu があれば、渡す前に yomiyasu スキルを呼び出し、書いた本文を渡して
整える。この規則は、ユーザーが yomiyasu を使うよう求める指示にあたる。文章の種類が分かっていれば、種類も渡す
（ユーザーへの返答は mail、コミットや PR は pr、README は article か manual、
規則や仕様書は formal）。表記を上で選んだ書き方にしたいときは、それも渡す。

## yomiyasu が無いときは、自分で整える

- 1つの文には1つのことだけを書く。2つ以上のことを書いた長い文は、切る。
- 主語と述語、修飾する語とされる語が離れていたら、近づける。
- 比喩・飾りの語・宣伝のような言い回しは、中身を表す言葉に置き換える。
- 予告だけの文（「次の点が重要です」）は、続く中身の文とまとめる。
- 表記を、上で選んだ書き方にそろえる。
- 最後に文頭から順に読み直す。前に戻って読み直した箇所があれば、そこを直す。
